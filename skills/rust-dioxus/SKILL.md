# Dioxus

Dioxus is a cross-platform UI framework for Rust. Write once, target web (WASM), desktop (native via WebView), mobile (iOS/Android), TUI, and SSR — all from the same codebase.

## Quick Setup

```bash
# Install CLI
cargo install dioxus-cli

# Create project
dx new my-app --template fullstack  # web + server
dx new my-app --template web        # WASM only
dx new my-app --template desktop    # Native desktop

# Dev server with hot reload
dx serve
```

```toml
# Cargo.toml
[dependencies]
dioxus = { version = "0.6", features = ["web"] } # or "desktop", "fullstack"
```

## Components & RSX

Dioxus components are plain Rust functions annotated with `#[component]`:

```rust
use dioxus::prelude::*;

fn main() {
    dioxus::launch(App);
}

#[component]
fn App() -> Element {
    rsx! {
        h1 { "Hello, Dioxus!" }
        Counter { initial: 0, label: "clicks" }
    }
}

// Props via struct (auto-generated by #[component])
#[component]
fn Counter(initial: i32, label: String) -> Element {
    let mut count = use_signal(|| initial);

    rsx! {
        div {
            class: "counter",
            p { "{count} {label}" }
            button {
                onclick: move |_| count += 1,
                "Increment"
            }
            button {
                onclick: move |_| count -= 1,
                "Decrement"
            }
        }
    }
}
```

### RSX Syntax

RSX is a compile-time macro that generates virtual DOM nodes:

```rust
rsx! {
    // HTML-like element
    div {
        // Attributes: no quotes for identifiers, quotes for CSS/custom
        class: "my-class",
        id: "main",
        style: "color: red",

        // Dynamic attributes
        class: if is_active { "active" } else { "inactive" },

        // Event handlers
        onclick: move |event| println!("Clicked: {:?}", event),
        oninput: move |e| name.set(e.value()),

        // Inline text
        "Static text"
        // Dynamic text
        "{variable}"

        // Conditional rendering
        if show_title {
            h1 { "Title" }
        }

        // List rendering
        for item in items.read().iter() {
            li { key: "{item.id}", "{item.name}" }
        }

        // Nested components
        MyComponent { prop: value }
    }
}
```

## Signals & State

Signals are Dioxus's reactive primitive — reads and writes tracked automatically:

```rust
use dioxus::prelude::*;

#[component]
fn StateDemo() -> Element {
    // Local state
    let mut counter = use_signal(|| 0i32);
    let mut name = use_signal(|| String::from("World"));

    // Derived state (re-computes when dependencies change)
    let doubled = use_memo(move || counter() * 2);

    rsx! {
        p { "Count: {counter}" }
        p { "Doubled: {doubled}" }
        p { "Hello, {name}!" }

        button { onclick: move |_| counter += 1, "+" }
        input {
            value: "{name}",
            oninput: move |e| name.set(e.value()),
        }
    }
}

// Reading signals: counter() or *counter.read()
// Writing signals: counter.set(5), counter += 1, *counter.write() = 5
```

## Async Data Fetching

```rust
use dioxus::prelude::*;

#[derive(serde::Deserialize, Clone)]
struct Post { id: u32, title: String, body: String }

#[component]
fn PostList() -> Element {
    // Async resource — fetches on mount, re-fetches on dependency change
    let posts = use_resource(|| async {
        reqwest::get("https://jsonplaceholder.typicode.com/posts")
            .await?
            .json::<Vec<Post>>()
            .await
    });

    match &*posts.read_unchecked() {
        None => rsx! { p { "Loading..." } },
        Some(Err(e)) => rsx! { p { "Error: {e}" } },
        Some(Ok(posts)) => rsx! {
            ul {
                for post in posts {
                    li { key: "{post.id}", "{post.title}" }
                }
            }
        }
    }
}

// Parameterized resource — re-fetches when `id` changes
#[component]
fn PostDetail(id: u32) -> Element {
    let post = use_resource(move || async move {
        reqwest::get(format!("https://jsonplaceholder.typicode.com/posts/{id}"))
            .await?
            .json::<Post>()
            .await
    });

    // ...
}
```

## use_effect

Side effects that run after rendering:

```rust
#[component]
fn Timer() -> Element {
    let mut seconds = use_signal(|| 0u32);

    use_effect(move || {
        // Runs after component mounts and when dependencies change
        let interval = gloo_timers::callback::Interval::new(1000, move || {
            seconds += 1;
        });
        // Return cleanup closure (called on unmount or re-run)
        move || drop(interval)
    });

    rsx! { p { "Elapsed: {seconds}s" } }
}
```

## Context (Global/Shared State)

```rust
use dioxus::prelude::*;

#[derive(Clone)]
struct ThemeContext {
    dark_mode: Signal<bool>,
}

#[component]
fn App() -> Element {
    // Provide context at the top level
    let ctx = use_context_provider(|| ThemeContext {
        dark_mode: Signal::new(false),
    });

    rsx! {
        div {
            class: if ctx.dark_mode() { "dark" } else { "light" },
            Toolbar {}
            Content {}
        }
    }
}

#[component]
fn Toolbar() -> Element {
    let mut ctx = use_context::<ThemeContext>();

    rsx! {
        button {
            onclick: move |_| {
                let current = ctx.dark_mode();
                ctx.dark_mode.set(!current);
            },
            "Toggle theme"
        }
    }
}
```

## Routing

```rust
use dioxus::prelude::*;
use dioxus_router::prelude::*;

#[derive(Routable, Clone)]
#[rustfmt::skip]
enum Route {
    #[layout(Layout)]
        #[route("/")]
        Home {},
        #[route("/posts")]
        PostList {},
        #[route("/posts/:id")]
        PostDetail { id: u32 },
        #[route("/about")]
        About {},
    #[end_layout]
    #[route("/:..segments")]
    NotFound { segments: Vec<String> },
}

#[component]
fn Layout() -> Element {
    rsx! {
        nav {
            Link { to: Route::Home {}, "Home" }
            Link { to: Route::PostList {}, "Posts" }
            Link { to: Route::About {}, "About" }
        }
        Outlet::<Route> {}
    }
}

#[component]
fn PostDetail(id: u32) -> Element {
    let nav = use_navigator();

    rsx! {
        h1 { "Post {id}" }
        button {
            onclick: move |_| nav.go_back(),
            "Back"
        }
    }
}
```

## Server Functions (Full-Stack)

Server functions run on the server, called from the client transparently:

```rust
use dioxus::prelude::*;
use server_fn::codec::Json;

#[server(GetUser)]
async fn get_user(id: u64) -> Result<User, ServerFnError> {
    // This code runs on the server
    let user = db::find_user(id).await?;
    Ok(user)
}

// Component calls it like any async function
#[component]
fn UserProfile(id: u64) -> Element {
    let user = use_resource(move || get_user(id));

    match &*user.read_unchecked() {
        None => rsx! { "Loading..." },
        Some(Ok(user)) => rsx! { h1 { "{user.name}" } },
        Some(Err(e)) => rsx! { p { "Error: {e}" } },
    }
}
```

## Styling

Dioxus supports inline styles, CSS classes, and CSS-in-Rust via `dioxus-sdk`:

```rust
// Inline styles
rsx! {
    div {
        style: "display: flex; flex-direction: column; gap: 8px;",
        "Content"
    }
}

// Dynamic classes (tailwind-friendly)
let is_active = use_signal(|| false);
rsx! {
    button {
        class: format!("btn {}", if is_active() { "btn-active" } else { "" }),
        "Click"
    }
}

// Global CSS (in asset pipeline)
const STYLE: &str = include_str!("./style.css");
rsx! {
    style { "{STYLE}" }
}
```

## Performance Tips

```rust
// 1. Use keys for lists — helps diffing
for item in items() {
    li { key: "{item.id}", "{item.name}" }
}

// 2. Memoize expensive computations
let expensive = use_memo(move || heavy_calculation(data()));

// 3. Avoid cloning in closures — capture Signal, not its value
let items = use_signal(|| vec![1, 2, 3]);
// Bad: moves clone into every render
// Good: capture the Signal itself
onclick: move |_| { items.write().push(4); }

// 4. Split large components — only re-render what changes
// Bad: one 500-line component
// Good: Child components with their own signals

// 5. use_resource caches results until deps change
```

## Common Patterns

```rust
// Controlled input
let mut value = use_signal(String::new);
rsx! {
    input {
        value: "{value}",
        oninput: move |e| value.set(e.value()),
    }
}

// Form submission
let mut form_data = use_signal(FormData::default);
let on_submit = move |e: Event<FormData>| {
    e.prevent_default();
    // handle form_data()
};

// Conditional component mounting (vs hiding)
if show_modal() {
    Modal { on_close: move |_| show_modal.set(false) }
}
// vs
div {
    display: if show_modal() { "block" } else { "none" },
    // ... (mounted but hidden)
}
```
